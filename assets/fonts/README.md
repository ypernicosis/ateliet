# Fonts bundled with the native app

- `Inter-*.ttf`: [Inter](https://rsms.me/inter/) 4.1 by Rasmus Andersson, SIL Open Font License 1.1 (`LICENSE-Inter.txt`). Subset to Latin, Latin Extended, punctuation, arrows and symbols with `pyftsubset … --layout-features='kern,liga,calt,tnum,case,ss01'`.
- `Lucide.ttf`: a subset of the [Lucide](https://lucide.dev) icon font (lucide-static 0.469.0), ISC License (`LICENSE-Lucide.txt`). The icons in use are listed in `lucide-icons.txt`; `subset.py` regenerates the font and `src/icons.rs`.
- `CormorantGaramond-*.ttf`: [Cormorant Garamond](https://github.com/CatharsisFonts/Cormorant), SIL Open Font License 1.1 (`LICENSE-CormorantGaramond.txt`), for map labels. `EBGaramond-*.ttf`: [EB Garamond](https://github.com/octaviopardo/EBGaramond12), SIL Open Font License 1.1 (`LICENSE-EBGaramond.txt`), for typeset pages. Both are static instances of the variable fonts (`fontTools.varLib.instancer … wght=500`, the bold at 700, names and weights set to match) subset to Latin, punctuation and dingbats (the ornaments ❦ ⁂) with `pyftsubset … --layout-features='kern,liga,onum,lnum,smcp,c2sc,pnum,tnum,sups,ccmp,locl'`.
- Fonts of the ready-made book styles, for typesetting only, all SIL Open Font License 1.1 from [Google Fonts](https://github.com/google/fonts) (`LICENSE-*.txt`): `Lora-*`, `CrimsonText-*`, `Cinzel-*`, `CinzelDecorative-Regular`, `PlayfairDisplay-*`, `LibreBaskerville-*`. Variable fonts instanced at weights 400 and 700 with `fontTools.varLib.instancer`, names and weights set to match, and subset like the Garamonds.
